# 隧道盾构机展示

这是一个可在浏览器运行的原理演示。页面是一张全屏的北京西城地图，设备和部件都在地图中查看。

[打开在线演示](https://weilb.github.io/tunnel-boring-machine-demo/)。`main` 分支更新时，GitHub Actions 会运行测试并把构建后的 `dist/` 发布到 GitHub Pages。

## 启动

使用 Node.js 22.12+ 与支持 WebGL 2 的浏览器（本项目使用 Node.js 22 验证）：

```sh
npm ci
npm run dev
```

打开终端打印的本地地址，默认 `http://127.0.0.1:5183/`。安装依赖后，页面不需要网络底图、API 密钥或第三方服务。请从本地服务器访问，不要直接双击 `index.html`。`npm test` 运行核心测试；`npm run build` 生成 `dist/`，`npm run preview` 预览生产构建。

## 怎么看

1. 默认打开西城区北海北站附近的 `EPB-01`。从「设备定位」可回到设备、查看西城周边，也可拖动、缩放地图。设备位置固定，不提供沿线控制。
2. 「透视联动」默认显示完整实体。点击地图模型或列表中的部件，地图镜头会靠近并转向它，外壳沿机身逐段变为半透明蓝色线框，所选部件高亮。再点一次同一列表项，或点击「整体定位」，返回整机。
3. 「原版剖视」用贴着选中部件表面的暖色扫光和缓慢呼吸光提示选中状态；选「螺旋输送机」时切出近侧外壳和筒壁，选其他部件仍显示完整外壳。透视联动中的盾壳使用冷色表面扫光，不增加装饰圈。切换展示方式时保留当前选择；没有选中部件时自动定位刀盘。
4. 刀盘默认以 `6 rpm` 播放，螺旋叶片默认以 `30 rpm` 播放。「动画设置」默认折叠，展开后可暂停机械转动或分别调速；切换展示方式不重置旋转相位。系统开启「减少动态效果」时，镜头与材质直接切换，选中光效保留静态边缘亮光。

## 资料、边界与替换

- 整机几何是 `src/model.ts` 的程序化示意，不是厂商 CAD。机头朝局部 `-X`；刀盘以机身纵轴旋转，螺旋叶片以倾角 `28°` 的局部轴旋转。完整筒体和有封边的剖切筒体是两套可见几何。替换真实装配时保留部件 ID、两根独立轴、米制比例和两种外壳状态。
- 结构参考海瑞克[原理图](https://www.herrenknecht.com.cn/produkte/productdetail/土压平衡式盾构机/)与 Lee 等人[论文](https://doi.org/10.3390/app11062551)的图 3、表 2（CC BY 4.0）；细节见同目录的 `资料与用法.md`。`screw-spin-demo.glb` 是保留的 CC0 通用输送机运动参照，不作为盾构整机资产载入页面。
- `src/data/beijing-xicheng.geojson` 包含什刹海片区及周边的道路、建筑轮廓、水域和绿地，来源为 2026-11-19 提取的 [© OpenStreetMap contributors](https://www.openstreetmap.org/copyright)，数据以 [ODbL 1.0](https://opendatacommons.org/licenses/odbl/1-0/) 提供。底图只覆盖本地演示区域，不使用在线瓦片。早期里昂场景的文件仍可作为素材参考，不在现页面加载。
- **设备位置、朝向、高度与转速均为模拟。** 演示点在 `src/site.ts` 以 WGS84 `[经度, 纬度]` 配置。模型放在地表以便观察，不代表真实施工点位、工况或埋深。
